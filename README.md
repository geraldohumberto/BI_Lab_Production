# Dashboard de Produção | Power BI

  Dashboard desenvolvido em Power BI para
  acompanhar indicadores de produção,
  identificar gargalos operacionais e apoiar
  decisões baseadas em dados.

  ![Prévia do dashboard](assets/dashboard/
  production-dashboard-preview.png)

  ## Objetivo

  Centralizar os principais indicadores da
  operação produtiva em um painel interativo,
  facilitando a análise de desempenho por
  período, produto, linha de produção e equipe.

  ## Indicadores analisados

  - Quantidade produzida;
  - Meta de produção;
  - Percentual de atingimento da meta;
  - Produtividade por colaborador ou equipe;
  - Produção por produto e categoria;
  - Evolução da produção ao longo do tempo;
  - Identificação de atrasos, perdas ou
  gargalos.

  ## Tecnologias utilizadas

  - **Power BI Desktop** — modelagem e criação
  do dashboard;
  - **Power Query** — limpeza, transformação e
  preparação dos dados;
  - **Excel/CSV** — fonte de dados do projeto;
  - **DAX** — criação de medidas e indicadores
  de desempenho.

  ## Estrutura do repositório

  ```text
  assets/dashboard/    # GIF e imagens de prévia
  do projeto
  data/raw/            # Base de dados original
  docs/                # Documentação e
  materiais de apoio
  production-dashboard.pbix  # Relatório final
  do Power BI

  ## Como explorar

  1. Baixe ou clone este repositório.
  2. Abra o arquivo .pbix no Power BI Desktop.
  3. Caso necessário, atualize o caminho da
     fonte de dados.

  4. Atualize os dados e navegue pelos
     indicadores do painel.

  ## Principais insights esperados

  Com este dashboard, é possível:

  - comparar a produção realizada com as metas
    estabelecidas;

  - identificar produtos, linhas ou períodos com
    menor desempenho;

  - acompanhar a evolução da produtividade;
  - apoiar ações para reduzir perdas e melhorar
    a eficiência operacional.

  ## Contexto do projeto

  Projeto desenvolvido para praticar análise de
  dados aplicada à área de produção, desde o
  tratamento da base até a construção de
  indicadores e visuais gerenciais no Power BI.
